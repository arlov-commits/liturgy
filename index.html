The words of the booklets are kept in a private GitHub repository. To show them, this page needs a GitHub key for that one repository. You do this once on each computer/browser.

  1. Open GitHub's “new key” page (sign in to GitHub if it asks).
  2. Token name: anything, e.g. “Liturgy booklet”. Expiration: how long the key should work — after that you make a new one.
  3. Resource owner: . Repository access: “Only select repositories” → .
  4. Permissions: add Contents and set it to Read and write (so Save works).
