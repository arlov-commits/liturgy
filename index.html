Connect to the liturgy text

The words of the booklets are kept in a private GitHub repository. To show them, this page needs a GitHub key for that one repository. You do this once on each computer/browser.

  1. Open GitHub's “new key” page (sign in to GitHub if it asks).
  2. Token name: anything, e.g. “Liturgy booklet”. Expiration: how long the key should work — after that you make a new one.
  3. Resource owner: . Repository access: “Only select repositories” → .
  4. Permissions: add Contents and set it to Read and write (so Save works).
  5. Click Generate token, copy the key (it starts with github_pat_) and paste it here:

The key is kept in this browser only. “Disconnect” in the top bar removes it.

Or work without GitHub:

Pick your copy of the liturgy-text folder (the one with “books” and “text” in it). The editor reads it and Save writes straight into it. Chrome or Edge on a computer only.

The editor was working from on this computer. The browser needs your OK to open it again.

Print on letter paper, 4 pages a side

  1. Save the booklet as a PDF. Click Print… at the top, choose Save as PDF as the destination, and save it. (The page size is set for you; leave margins on “Default”.)
  2. Make the letter sheets. Choose that PDF here:
  3. Print the sheets PDF on letter paper, both sides, flip on long edge, at actual size / 100% (not “fit to page”).
  4. Cut each sheet into four, across the middle both ways. Keep four piles — top-left, top-right, bottom-left, bottom-right — each in the order the sheets came out of the printer, sheet 1 on top.
  5. Stack the piles: top-left on top of top-right, on top of bottom-left, on top of bottom-right. The pages are now in order (check a few page numbers), ready to glue.
